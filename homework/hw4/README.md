## 1. Выявление Доменного сервиса

Операция изменения статуса заявки - это комплексная операция, которая не может быть выполнена в рамках одного агрегата. Самая объемная логика связана с закрытием заяки . Закрытие звявки должно изменить статус заявки, сохранить заполненный чек-лист, инициировать генерацию отчетных документов и отправку уведомлений.
